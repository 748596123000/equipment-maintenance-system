## 3. Docker部署（推荐）

### 3.1 部署步骤

#### 3.1.1 下载源代码
```bash
# 克隆代码仓库
git clone https://github.com/748596123000/equipment-maintenance-system.git
cd equipment-maintenance-system
```

#### 3.1.2 配置环境变量
```bash
# 复制环境变量模板
cp .env.example .env

# 编辑.env文件
nano .env  # 或使用其他编辑器
```

**重要配置项**：
```env
# 通义千问API密钥（必需）
DASHSCOPE_API_KEY=your_api_key_here

# 环境模式
ENVIRONMENT=production
DEBUG=False

# 允许的跨域来源
CORS_ORIGINS=["http://your-domain.com"]

# 允许的Host
ALLOWED_HOSTS=["your-domain.com", "localhost"]
```

#### 3.1.3 构建并启动
```bash
# CPU版本
docker compose up -d --build

# GPU版本（需要NVIDIA Docker支持）
docker compose -f docker-compose.gpu.yml up -d --build
```

#### 3.1.4 验证部署
```bash
# 检查服务状态
docker compose ps

# 检查健康状态
curl http://localhost:8000/health
```

### 3.2 Docker Compose配置

#### 3.2.1 CPU版本 (docker-compose.yml)
```yaml
version: '3.8'

services:
  backend:
    build: .
    container_name: equipment-backend
    ports:
      - "8000:8000"
    volumes:
      - ./data:/app/data
      - ./samples:/app/samples
    environment:
      - ENVIRONMENT=production
      - DEBUG=False
    env_file:
      - .env
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 10s
      retries: 3

  frontend:
    image: nginx:alpine
    container_name: equipment-frontend
    ports:
      - "80:80"
    volumes:
      - ./frontend/dist:/usr/share/nginx/html:ro
    depends_on:
      - backend
    restart: unless-stopped
```

#### 3.2.2 GPU版本 (docker-compose.gpu.yml)
```yaml
version: '3.8'

services:
  backend:
    build:
      context: .
      dockerfile: Dockerfile.gpu
    container_name: equipment-backend-gpu
    ports:
      - "8000:8000"
    volumes:
      - ./data:/app/data
      - ./samples:/app/samples
      - nvidia_driver_535_driver:/usr/local/nvidia/drivers:ro
    environment:
      - ENVIRONMENT=production
      - DEBUG=False
      - NVIDIA_VISIBLE_DEVICES=all
      - NVIDIA_DRIVER_CAPABILITIES=all
    env_file:
      - .env
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
    restart: unless-stopped
    runtime: nvidia

  frontend:
    image: nginx:alpine
    container_name: equipment-frontend
    ports:
      - "80:80"
    volumes:
      - ./frontend/dist:/usr/share/nginx/html:ro
    depends_on:
      - backend
    restart: unless-stopped
```

### 3.3 Nginx配置
```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    root /usr/share/nginx/html;
    index index.html;

    # 前端静态文件
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api {
        proxy_pass http://equipment-backend:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # 健康检查
    location /health {
        proxy_pass http://equipment-backend:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
    }
}
```

## 4. 手动部署

### 4.1 后端部署

#### 4.1.1 创建虚拟环境
```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux/Mac
python3 -m venv .venv
source .venv/bin/activate
```

#### 4.1.2 安装依赖
```bash
# 安装CPU版本依赖
pip install -r requirements.txt

# 安装GPU版本依赖（可选）
pip install -r requirements-gpu.txt
```

#### 4.1.3 配置环境变量
```bash
# 复制环境变量模板
cp .env.example .env

# 编辑.env文件
notepad .env  # Windows
nano .env     # Linux
```

**完整配置示例**：
```env
# 通义千问API配置
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxx

# LLM配置
LLM_BACKEND=dashscope
LLM_MODEL=qwen-max
LLM_TEMPERATURE=0.7
LLM_MAX_TOKENS=4096

# 向量化配置
EMBEDDING_MODEL=text-embedding-v3

# 数据库配置
CHROMA_PERSIST_DIR=./data/chroma_db
SQLITE_DB_PATH=./data/app.db

# 服务配置
API_HOST=0.0.0.0
API_PORT=8000
DEBUG=False
ENVIRONMENT=production

# 安全配置
SECRET_KEY=your-secret-key-here
ACCESS_TOKEN_EXPIRE_HOURS=24

# 跨域配置
CORS_ORIGINS=["http://localhost:3000"]
ALLOWED_HOSTS=["localhost", "127.0.0.1"]
```

#### 4.1.4 初始化数据库
```bash
# 启动服务时会自动初始化
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

#### 4.1.5 使用systemd服务（Linux）
创建服务文件 `/etc/systemd/system/equipment.service`：
```ini
[Unit]
Description=Equipment Maintenance System
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/equipment-maintenance-system
ExecStart=/opt/equipment-maintenance-system/.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable equipment
sudo systemctl start equipment
sudo systemctl status equipment
```

## 5. 银河麒麟/龙芯部署

### 5.1 使用部署脚本

项目提供了专门的部署脚本 `deploy/kylin_setup.sh`：

```bash
# 给脚本添加执行权限
chmod +x deploy/kylin_setup.sh

# 运行部署脚本
sudo bash deploy/kylin_setup.sh
```

### 5.2 手动部署步骤

#### 5.2.1 系统检测
```bash
# 检查系统架构
uname -m
# 期望输出：loongarch64 或 aarch64

# 检查操作系统
cat /etc/kylin-release
```

#### 5.2.2 安装依赖
```bash
# CentOS/RHEL系
sudo yum install -y python3 python3-pip python3-venv nginx

# Debian系（银河麒麟部分版本）
sudo apt update
sudo apt install -y python3 python3-pip python3-venv nginx
```

#### 5.2.3 部署步骤
```bash
# 1. 创建应用目录
sudo mkdir -p /opt/equipment-maintenance-system
sudo chown $USER:$USER /opt/equipment-maintenance-system
cd /opt/equipment-maintenance-system

# 2. 复制代码
# （通过U盘、网络等方式复制代码包）
# 解压到当前目录

# 3. 配置Python环境
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 4. 配置环境变量
cp .env.example .env
nano .env  # 编辑配置

# 5. 配置Nginx
sudo cp deploy/nginx.conf /etc/nginx/conf.d/equipment.conf
sudo nginx -t
sudo systemctl enable nginx
sudo systemctl start nginx

# 6. 配置systemd服务
sudo cp deploy/equipment.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable equipment
sudo systemctl start equipment
```

### 5.3 银河麒麟部署配置

#### 5.3.1 Nginx配置 (deploy/nginx.conf)
```nginx
server {
    listen 80;
    server_name _;
    
    root /opt/equipment-maintenance-system/frontend/dist;
    index index.html;

    # Gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
    
    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # SSE支持
        proxy_cache off;
        proxy_buffering off;
        proxy_read_timeout 86400;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
}
```

#### 5.3.2 systemd服务配置 (deploy/equipment.service)
```ini
[Unit]
Description=Equipment Maintenance System
After=network.target nginx.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/equipment-maintenance-system
Environment="PATH=/opt/equipment-maintenance-system/.venv/bin"
ExecStart=/opt/equipment-maintenance-system/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 2
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

### 5.4 开机自启动配置
```bash
# 启用服务开机自启动
sudo systemctl enable equipment nginx

# 检查服务状态
sudo systemctl status equipment
sudo systemctl status nginx
```

## 6. 数据管理

### 6.1 数据目录结构
```
data/

├── chroma_db/          # ChromaDB向量数据库
│   └── chroma.sqlite3
```

### 6.2 数据备份
```bash
# 备份脚本
#!/bin/bash
BACKUP_DIR="/opt/backups"
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR

# 备份数据库
cp data/app.db $BACKUP_DIR/app_$DATE.db

# 备份向量数据库
cp -r data/chroma_db $BACKUP_DIR/chroma_db_$DATE

# 备份配置
cp .env $BACKUP_DIR/env_$DATE

# 清理30天前的备份
find $BACKUP_DIR -mtime +30 -delete

echo "Backup completed: $DATE"
```

### 6.3 数据恢复
```bash
# 停止服务
sudo systemctl stop equipment

# 恢复数据库
cp backup/app_20260520.db data/app.db

# 恢复向量数据库
rm -rf data/chroma_db
cp -r backup/chroma_db_20260520 data/chroma_db

# 重启服务
sudo systemctl start equipment
```

## 9. 故障排除

### 9.1 常见问题

#### 问题1：服务启动失败
**症状**：执行 `docker compose up` 或 `uvicorn` 失败

**解决方案**：
1. 检查端口占用：`lsof -i :8000`
2. 检查日志：`docker logs equipment-backend` 或查看 `data/logs/`
3. 检查配置：确保 `.env` 文件存在且配置正确

#### 问题2：API无法访问
**症状**：前端显示"后端服务不可用"

**解决方案**：
1. 检查后端服务状态：`curl http://localhost:8000/health`
2. 检查Nginx配置：`sudo nginx -t`
3. 检查防火墙：`sudo ufw status`

#### 问题3：检索无结果
**症状**：搜索不到任何内容

**解决方案**：
1. 检查是否已上传文档
2. 检查文档是否已审核通过
3. 检查ChromaDB是否正常

### 9.2 日志分析
```bash
# 查看最近错误
grep ERROR data/logs/app_*.log | tail -50

# 查看特定接口日志
grep "/api/v1/search" data/logs/app_*.log

# 实时查看日志
tail -f data/logs/app_*.log
```
