## 一、项目概述

### 1.1 背景与痛点

电力设备检修是保障电网安全运行的关键环节，传统检修模式面临以下挑战：

| 痛点 | 传统方式 | 我们的解决方案 |
|------|---------|----------------|
| 知识分散 | 纸质手册、经验传承 | 多模态知识库统一管理 |
| 检修效率低 | 人工查阅大量文档 | AI智能检索、即问即答 |
| 操作风险高 | 凭经验操作 | 风险评估 + 合规校验 |
| 人员水平差异 | 新人培训周期长 | 个性化指引因材施教 |
| 跨设备检索难 | 单一关键词搜索 | 文本+图片多模态检索 |

### 1.2 项目目标

构建一套基于多模态大模型的设备检修知识检索与作业系统，实现：
- **智能化**：AI赋能，知识检索和作业指引生成自动化
- **多模态**：支持文本、图片、设备铭牌等多种输入方式
- **安全化**：内置风险评估和合规校验，保障作业安全
- **信创化**：支持龙芯架构和银河麒麟操作系统

## 二、技术创新点

### 2.1 多模态融合检索技术

#### 创新点描述

传统RAG系统仅支持文本检索，本项目创新性地实现了**文本+图片+设备铭牌**的多模态融合检索。

#### 技术实现

```
用户查询（文本/图片）
    ↓
┌─────────────────────────────────────────┐
│          多模态检索引擎                  │
├─────────────────────────────────────────┤
│  文本检索 → TF-IDF + 向量相似度 (RRF融合) │
│  图片检索 → Qwen2-VL视觉理解 → 文本描述  │
│  铭牌识别 → 设备型号自动提取 → 知识关联  │
└─────────────────────────────────────────┘
    ↓
融合排序 → 返回精准结果
```

#### 关键创新

1. **以图搜文**：上传设备铭牌照片，AI自动识别型号并检索相关知识
2. **跨模态对齐**：使用视觉语言模型建立图片和文本的语义关联
3. **RRF融合算法**：Reciprocal Rank Fusion融合多路检索结果

#### 对比优势

| 方案 | 文本检索 | 图片检索 | 铭牌识别 |
|------|---------|---------|---------|
| 传统方案 | ✅ | ❌ | ❌ |
| 竞品A | ✅ | 基础 | ❌ |
| **本项目** | ✅ | ✅ Qwen2-VL | ✅ 视觉AI |
