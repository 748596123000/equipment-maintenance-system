# 设备检修知识检索与作业系统 - 演示PPT大纲

## 项目：基于多模态大模型技术的设备检修知识检索与作业系统

---

## 第1页：封面
- **标题**：设备检修知识检索与作业系统
- **副标题**：基于多模态大模型技术的智能检修方案
- **团队信息**
- **日期**

---

## 第2页：项目概述
- **项目背景**：工业设备检修知识分散、检索低效、新人上手慢
- **解决问题**：
  - 知识分散，难以快速检索
  - 经验传承困难
  - 标准化程度低
- **核心价值**：提高检修效率，降低操作失误，积累企业知识

---

## 第3页：技术架构
- **前端**：React + TypeScript + Tailwind CSS
- **后端**：FastAPI + Python
- **向量数据库**：ChromaDB
- **大模型**：阿里云通义千问
- **部署**：Docker容器化，支持国产操作系统
- **系统架构图**

---

## 第4页：核心功能（上）
1. **多模态知识检索**
   - 文本检索（语义搜索）
   - 图片检索（以图搜图）
   - 混合检索（图文结合）
   - 实时搜索历史

2. **AI智能问答**
   - 自然语言交互
   - 故障诊断辅助
   - 多轮对话支持
   - 知识溯源

---

## 第5页：核心功能（下）
3. **标准化作业指引**
   - AI生成作业指导书
   - 多安全等级配置
   - Word格式导出
   - 历史指引复用

4. **知识沉淀与更新**
   - 文档上传与审核
   - 案例管理

   - 持续更新机制
