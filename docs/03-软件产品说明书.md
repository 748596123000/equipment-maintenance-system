# 软件产品说明书

## 产品名称
基于多模态大模型技术的设备检修知识检索与作业系统

## 版本信息
- 产品版本：V1.0.0
- 发布日期：2026-05-20
- 文档版本：V1.0.0

## 1. 产品概述

### 1.1 产品简介
本产品是第十五届中国软件杯大赛（A组）参赛作品，聚焦工业设备检修领域，采用多模态大模型技术，为一线检修人员提供智能化的知识检索、故障诊断辅助和标准化作业指引功能。

### 1.2 核心价值
- **知识智能化**：将分散的检修知识整合为可检索的智能知识库
- **检索精准化**：支持文本、图片等多种检索方式，快速定位所需信息
- **操作规范化**：提供标准化的作业指导，降低操作失误率
- **经验传承化**：实现检修经验的数字化沉淀和高效复用

### 1.3 目标用户
- 一线检修人员
- 技术专家
- 知识工程师
- 系统管理员

## 2. 功能特性

### 2.1 用户管理

#### 2.1.1 用户登录
- 支持用户名+密码+验证码登录
- 支持Bearer Token认证
- 24小时Token有效期
- 登录失败锁定机制（5次/5分钟）

#### 2.1.2 用户注册
- 支持自主注册申请
- 管理员审批制
- 完整的用户信息管理

### 2.2 知识检索

#### 2.2.1 文本语义检索
基于向量相似度的语义理解检索，能够理解查询意图，返回最相关的知识内容。

**特点**：
- 语义理解，模糊查询支持
- 相似度排序
- 相关性评分

**示例**：输入"发动机无法启动"，系统可检索到关于发动机启动故障的相关文档。

#### 2.2.2 关键词检索
基于关键词的精确匹配检索，支持AND/OR组合查询。

**特点**：
- 精确关键词匹配
- 关键词高亮显示
- 布尔查询支持

#### 2.2.3 混合检索
融合语义检索和关键词检索的结果，提供更全面的检索体验。

**特点**：
- RRF融合算法
- 可调整语义/关键词权重
- 智能关键词提取

#### 2.2.4 图片检索
上传故障图片，查找相似的故障案例和解决方案。

**特点**：
- 支持JPG、PNG等格式
- 视觉特征提取
- 相似图片推荐

#### 2.2.5 多模态检索
同时支持文本和图片的混合检索，更全面地获取知识。

**特点**：
- 跨模态语义匹配
- 文本+图片联合查询
- 综合结果排序

### 2.3 AI智能问答

#### 2.3.1 智能问答
基于RAG技术的智能问答系统，结合知识库检索和大模型生成能力。

**特点**：
- 检索增强生成
- 答案来源追溯
- 多轮对话支持
- 图片输入支持

#### 2.3.2 上下文记忆
支持多轮对话，系统能够记忆之前的对话内容，提供连贯的问答体验。

**特点**：
- 最近10轮对话记忆
- 会话历史管理
- 支持新建会话

#### 2.3.3 知识溯源
每个回答都附带知识来源，便于用户查阅原始文档。

**特点**：
- 显示来源文档
- 相似度分数
- 点击跳转到原文

### 2.4 作业指引

#### 2.4.1 指引生成
根据设备型号和故障类型，自动生成标准化的作业指导书。

**特点**：
- 设备类型选择
- 故障描述输入
- 安全等级设置
- 详细程度可调
- 流式生成展示

#### 2.4.2 指引管理
管理历史生成的作业指引，支持查看和删除操作。

**特点**：
- 指引列表展示
- 分类筛选
- 搜索功能

#### 2.4.3 Word导出
支持将生成的作业指引导出为Word文档。

**特点**：
- 格式保留
- 离线可用
- 打印支持

### 2.5 案例管理

#### 2.5.1 案例创建
记录完整的检修案例，包括故障描述、解决方案、经验总结等。

**特点**：
- 结构化录入
- 附件上传支持
- 自动保存草稿

#### 2.5.2 案例审核
管理员审核用户提交的案例，确保案例质量。

**特点**：
- 待审核列表
- 审核通过/拒绝
- 审核意见反馈

#### 2.5.3 案例检索
检索历史检修案例，学习借鉴已有经验。

**特点**：
- 全文检索
- 分类筛选
- 分页浏览

#### 2.5.4 案例统计
统计案例数据，了解知识积累情况。

**特点**：
- 总量统计
- 状态分布
- 时间趋势

### 2.6 文档管理

#### 2.6.1 文档上传
上传检修相关文档，系统自动解析并存储。

**支持格式**：
- PDF
- Word (.docx)
- Excel (.xlsx)
- PowerPoint (.pptx)
- 图片 (JPG, PNG, BMP, GIF)
- 文本文件 (TXT, MD)

**特点**：
- 自动格式识别
- 大小限制：50MB
- 分类标签设置

#### 2.6.2 文档解析
智能解析上传的文档，提取文本内容和图片。

**技术特点**：
- PDF：文本和图片提取
- Word：段落和表格解析
- 图片：OCR文字识别
- 视觉描述：图片内容理解

#### 2.6.3 文档审核
管理员审核上传的文档。

**特点**：
- 待审核列表
- 预览功能
- 审核意见

#### 2.6.4 文档预览
在线预览文档内容。

**特点**：
- PDF预览
- 图片预览
- Word在线预览

#### 2.6.5 文档下载
下载原始文档文件。

**特点**：
- 原始格式保留
- 批量下载支持

### 2.7 知识图谱

#### 2.7.1 图谱可视化
交互式展示设备、故障、解决方案之间的知识关系。

**特点**：
- 力导向布局
- 节点类型区分（设备/故障/解决方案/操作流程/标准规范）
- 关系类型可视化

**特点**：

#### 2.7.3 图谱搜索

**特点**：
- 关键词搜索

- 节点聚焦

#### 2.7.4 节点详情
查看图谱节点的详细信息和关联关系。

**特点**：
- 节点属性展示
- 关联边展示
- 跳转功能

#### 2.8.1 用户管理

**特点**：

## 3. 技术规格

### 3.1 系统架构
- **架构类型**：B/S（浏览器/服务器）
- **前端**：React 18 + Vite 5 + TypeScript
- **后端**：Python 3.10 + FastAPI 0.115
- **数据库**：SQLite + ChromaDB向量数据库

### 3.2 支持平台
| 平台 | 操作系统 | 浏览器 | 状态 |
|------|---------|--------|------|
| PC端 | Windows 10+ | Chrome/Firefox/Edge | ✅ 支持 |
| PC端 | Linux (x86_64) | Chrome/Firefox | ✅ 支持 |
| PC端 | 银河麒麟 V10/V11 | 主流浏览器 | ✅ 支持 |
| PC端 | 龙芯 + 银河麒麟 | 主流浏览器 | ✅ 支持 |

### 3.3 硬件要求
- **CPU**：四核及以上
- **内存**：8GB及以上（GPU模式建议16GB+）
- **硬盘**：256GB及以上
- **GPU**（可选）：NVIDIA CUDA支持，用于加速文档解析

### 3.4 性能指标
| 指标 | 要求 |
|------|------|
| 登录响应时间 | < 1秒 |
| 知识检索响应 | < 2秒 |
| AI问答首响应 | < 3秒 |
| 文档上传 | < 5秒 |
| 系统可用性 | 99.5% |

## 4. 安装部署

### 4.1 部署方式

#### 4.1.1 Docker部署（推荐）
```bash
# 复制环境变量文件
cp .env.example .env
# 编辑.env文件，配置API密钥

# 启动服务
docker compose up -d
```

#### 4.1.2 手动部署
```bash
# 1. 安装Python依赖
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# 或 .venv\Scripts\activate  # Windows
pip install -r requirements.txt

# 2. 安装前端依赖并构建
cd frontend
npm install
npm run build
cd ..

# 3. 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 4.2 银河麒麟/龙芯部署
```bash
# 使用专用部署脚本
bash deploy/kylin_setup.sh
```

### 4.3 配置说明

创建或编辑 `.env` 文件：
```env
# 通义千问API密钥（必需）
DASHSCOPE_API_KEY=your_api_key_here

# 环境配置
ENVIRONMENT=production
DEBUG=False

# 跨域配置
CORS_ORIGINS=["http://localhost:3000"]
ALLOWED_HOSTS=["localhost", "127.0.0.1"]
```

## 5. 使用指南

### 5.1 首次登录
1. 打开系统地址：`http://localhost:3000`
2. 使用管理员账号登录
3. 在"API管理"中配置LLM服务
4. 开始使用系统

### 5.2 知识检索流程
1. 进入"知识检索"页面
2. 输入检索关键词或上传图片
3. 选择检索模式（语义/关键词/混合）
4. 查看检索结果
5. 点击查看原文详情

### 5.3 AI问答流程
1. 进入"知识检索"页面
2. 切换到"文本检索"标签
3. 输入问题
4. 系统返回AI回答和知识来源
5. 可继续追问，系统记忆上下文

### 5.4 生成作业指引流程
1. 进入"作业指引"页面
2. 点击"生成指引"
3. 选择设备类型，输入故障描述
4. 设置安全等级和详细程度
5. 系统生成指引，可导出为Word

### 5.5 案例提交流程
1. 进入"案例管理"页面
2. 点击"新建案例"
3. 填写案例信息
4. 上传相关附件
5. 提交审核
6. 等待管理员审批

## 7. 故障排除

### 7.1 常见问题

| 问题 | 解决方案 |
|------|---------|
| 登录失败 | 检查用户名密码，确保验证码正确 |
| 检索无结果 | 尝试调整关键词，或上传相关文档 |
| AI问答无响应 | 检查API配置，确保API密钥有效 |
| 文档上传失败 | 检查文件格式和大小限制 |
| 图谱为空 | 执行实体抽取操作 |

### 7.2 日志查看
```bash
# 查看应用日志
tail -f data/logs/app_*.log

# 查看错误日志
grep ERROR data/logs/app_*.log
```
