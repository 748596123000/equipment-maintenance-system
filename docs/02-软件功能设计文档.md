# 软件功能设计文档

## 项目名称
基于多模态大模型技术的设备检修知识检索与作业系统

## 版本信息
- 版本号：V1.0.0
- 日期：2026-05-20
- 文档状态：正式版

## 1. 引言

### 1.1 文档目的
本文档详细描述系统的软件架构、模块设计、数据库设计和接口设计，为开发团队提供具体的技术实现指导。

### 1.2 设计原则
- **模块化设计**：高内聚、低耦合，便于维护和扩展
- **可配置性**：核心参数可配置，支持多后端切换
- **容错设计**：完善的异常处理和降级机制
- **性能优化**：缓存策略、异步处理、资源复用
- **安全优先**：默认安全设计理念

## 4. 数据库设计

### 4.1 SQLite数据库表结构

#### 4.1.1 用户表 (users)
```sql
CREATE TABLE users (
    id TEXT PRIMARY KEY,
    username TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    real_name TEXT,
    email TEXT,
    phone TEXT,
    role TEXT DEFAULT 'user',
    status TEXT DEFAULT 'pending',
    created_at TEXT NOT NULL,
    updated_at TEXT
);
```

#### 4.1.2 Token表 (tokens)
```sql
CREATE TABLE tokens (
    token TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    expires_at TEXT NOT NULL,
    created_at TEXT NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 4.1.3 案例表 (cases)
```sql
CREATE TABLE cases (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    title TEXT NOT NULL,
    device_model TEXT,
    fault_type TEXT,
    description TEXT,
    solution TEXT,
    fault_analysis TEXT,
    repair_process TEXT,
    lessons_learned TEXT,
    attachments TEXT,
    status TEXT DEFAULT 'pending',
    review_comment TEXT,
    reviewed_by TEXT,
    reviewed_at TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 4.1.4 文档表 (documents)
```sql
CREATE TABLE documents (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    filename TEXT NOT NULL,
    file_type TEXT NOT NULL,
    file_size INTEGER,
    file_path TEXT,
    category TEXT DEFAULT '通用',
    page_count INTEGER,
    chunk_count INTEGER,
    status TEXT DEFAULT 'pending',
    review_comment TEXT,
    reviewed_by TEXT,
    reviewed_at TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 4.1.5 会话表 (chat_sessions)
```sql
CREATE TABLE chat_sessions (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    title TEXT,
    session_key TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 4.1.6 消息表 (chat_messages)
```sql
CREATE TABLE chat_messages (
    id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL,
    role TEXT NOT NULL,
    content TEXT NOT NULL,
    image_url TEXT,
    sources TEXT,
    created_at TEXT NOT NULL,
    FOREIGN KEY (session_id) REFERENCES chat_sessions(id)
);
```

#### 4.1.7 作业指引表 (guides)
```sql
CREATE TABLE guides (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    title TEXT NOT NULL,
    content TEXT,
    device_type TEXT,
    fault_type TEXT,
    safety_level TEXT,
    file_path TEXT,
    created_at TEXT NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 4.1.8 知识图谱节点表 (knowledge_graph_nodes)
```sql
CREATE TABLE knowledge_graph_nodes (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    type TEXT NOT NULL,
    properties TEXT,
    created_at TEXT NOT NULL
);
```

#### 4.1.9 知识图谱边表 (knowledge_graph_edges)
```sql
CREATE TABLE knowledge_graph_edges (
    id TEXT PRIMARY KEY,
    source_id TEXT NOT NULL,
    target_id TEXT NOT NULL,
    relation TEXT NOT NULL,
    weight REAL DEFAULT 1.0,
    properties TEXT,
    created_at TEXT NOT NULL,
    FOREIGN KEY (source_id) REFERENCES knowledge_graph_nodes(id),
    FOREIGN KEY (target_id) REFERENCES knowledge_graph_nodes(id)
);
```

#### 4.1.10 系统配置表 (system_config)
```sql
CREATE TABLE system_config (
    key TEXT PRIMARY KEY,
    value TEXT,
    updated_at TEXT
);
```

#### 4.1.11 操作日志表 (logs)
```sql
CREATE TABLE logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT,
    action TEXT NOT NULL,
    detail TEXT,
    ip_address TEXT,
    created_at TEXT NOT NULL
);
```

## 6. 安全设计

### 6.1 认证授权流程

```
用户请求
    │
    ▼
┌──────────────────┐
│  Token验证        │
└────────┬─────────┘
         │
    ┌────┴────┐
    │         │
    ▼         ▼
┌───────┐ ┌───────┐
│ 有效  │ │ 无效  │
    │         │
    ▼         ▼
┌───────┐ ┌───────┐
│ 权限  │ │ 401   │
│ 检查  │ │ 返回  │
└───┬───┘ └───────┘
    │
┌───┴───┐
│       │
▼       ▼
┌───┐ ┌───┐
│有 │ │无 │
│权 │ │权 │
└─┬─┘ └───┘
  │       │
  ▼       ▼
┌───┐ ┌───┐
│放 │ │403│
│行 │ │返 │
│  │ │回 │
└─┬─┘ └───┘
  │
  ▼

```

### 6.2 密码安全
- 使用bcrypt算法加密
- 自动升级旧版SHA256哈希
- 密码强度要求：至少8位

### 6.3 速率限制
| 接口类型 | 限制 | 时间窗口 |
|---------|------|---------|
| 登录 | 5次 | 5分钟 |
| API | 60次 | 1分钟 |

### 6.4 输入验证
- Pydantic模型自动验证
- SQL参数化查询

## 10. 扩展性设计

### 10.1 多LLM后端支持
通过 `LLM_PROVIDER_INFO` 配置表，支持新增LLM提供商：
```python
LLM_PROVIDER_INFO = {
    "provider_name": {
        "name": "显示名称",
        "url": "API地址",
        "models": [...]
    }
}
```

### 10.2 向量数据库可替换
抽象 `EmbeddingService` 接口，支持切换向量数据库：
- ChromaDB
- Milvus
- Qdrant
- FAISS
