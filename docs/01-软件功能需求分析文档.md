## 1. 引言

### 1.1 文档目的
本文档旨在详细描述"基于多模态大模型技术的设备检修知识检索与作业系统"的功能需求，为开发团队提供明确的技术实现指导，并为项目评审提供依据。

### 1.2 项目背景
本项目是第十五届中国软件杯大赛参赛作品（A组赛题），由龙芯中科技术股份有限公司出题。赛题聚焦工业、能源、制造等领域设备检修的核心痛点，以多模态大模型技术为核心支撑，开发一款兼具智能化、实用性与创新性的设备检修知识检索与作业辅助系统。

### 1.3 术语定义
| 术语 | 定义 |
|------|------|
| RAG | Retrieval-Augmented Generation，检索增强生成 |
| ChromaDB | 向量数据库，用于存储和检索文本嵌入向量 |
| OCR | Optical Character Recognition，光学字符识别 |
| LLM | Large Language Model，大语言模型 |
| 多模态 | 支持文本、图像等多种数据类型的处理能力 |
| 知识图谱 | 用图结构表示知识的方法，包含实体和关系 |

### 1.4 参考标准
- GB/T 8566-2007 软件生存周期过程
- GB/T 9385-2008 计算机软件需求规格说明规范
- ISO/IEC 25010 软件产品质量要求和评价标准

## 2. 系统概述

### 2.1 系统定位
系统定位为面向工业设备检修领域的智能助手，通过融合多模态大模型技术，实现检修知识的智能检索、故障诊断辅助、标准化作业指引等功能，助力行业数字化转型。

### 2.2 目标用户
| 用户类型 | 描述 | 主要功能 |
|---------|------|---------|
| 一线检修人员 | 执行设备检修操作的现场工作人员 | 知识检索、故障查询、作业指引 |
| 技术专家 | 负责疑难故障诊断和技术指导 | 案例审核、知识图谱管理 |
| 知识工程师 | 负责知识库维护和知识沉淀 | 文档管理、实体抽取 |
| 系统管理员 | 负责系统运维和配置管理 | 用户管理、API配置、系统监控 |

### 2.3 系统边界

#### 2.3.1 输入
- 用户提交的文本查询
- 用户上传的故障图片
- 用户上传的检修文档（PDF、Word、图片等）
- 管理员配置的API密钥和模型参数

#### 2.3.2 输出
- 检索结果列表
- AI问答回复
- 生成的作业指导书
- 知识图谱可视化

## 3. 功能需求

### 3.1 用户认证模块

#### 3.1.1 用户登录
- **功能描述**：用户通过用户名、密码和图形验证码登录系统
- **输入**：用户名、密码、验证码
- **输出**：登录成功返回JWT Token，失败返回错误信息
- **业务流程**：
  1. 用户输入用户名、密码
  2. 系统生成并显示图形验证码
  3. 用户提交登录请求
  4. 系统验证信息
  5. 验证通过返回Token，失败返回错误
- **约束条件**：
  - 同一IP 5分钟内连续失败5次将临时封禁
  - Token有效期24小时
  - 密码使用bcrypt加密存储

#### 3.1.2 用户注册
- **功能描述**：新用户提交注册申请，需管理员审批
- **输入**：用户名、密码、确认密码、真实姓名、邮箱、手机号
- **输出**：注册申请提交成功提示
- **业务流程**：
  1. 用户填写注册信息
  2. 系统验证信息格式
  3. 创建待审核用户记录
  4. 通知管理员审批
  5. 审批通过后账号激活

#### 3.1.3 用户登出
- **功能描述**：用户退出登录，清除本地Token
- **输入**：无
- **输出**：登出成功提示

#### 3.1.4 个人信息管理
- **功能描述**：查看和修改个人基本信息
- **输入**：用户名（只读）、真实姓名、邮箱、手机号
- **输出**：更新成功/失败提示

### 3.2 知识检索模块

#### 3.2.1 文本语义检索
- **功能描述**：基于向量相似度的语义理解检索
- **输入**：检索关键词
- **输出**：检索结果列表（包含相关文档片段、相似度分数、来源信息）
- **技术要求**：
  - 使用通义千问Embedding API进行向量化
  - ChromaDB存储和检索向量
  - 支持TopK参数配置（默认5条）

#### 3.2.2 关键词检索
- **功能描述**：基于TF-IDF的关键词精确匹配
- **输入**：关键词列表
- **输出**：包含关键词的文档列表
- **技术要求**：
  - 支持AND/OR匹配模式
  - 支持关键词高亮显示

#### 3.2.3 混合检索
- **功能描述**：融合语义检索和关键词检索结果
- **输入**：检索查询
- **输出**：综合评分排序的检索结果
- **技术要求**：
  - 使用RRF（倒数排名融合）算法
  - 默认权重：语义70%，关键词30%

#### 3.2.4 图片检索（以图搜图）
- **功能描述**：上传故障图片，查找相似图片和关联文档
- **输入**：故障图片（支持JPG、PNG、BMP等）
- **输出**：相似图片列表和相关文档
- **技术要求**：
  - 使用视觉模型提取图片特征
  - 图片相似度阈值可配置

#### 3.2.5 多模态检索
- **功能描述**：同时支持文本和图片的混合检索
- **输入**：文本描述 + 图片
- **输出**：综合检索结果
- **技术要求**：
  - 文本和图片分别编码
  - 多模态特征融合

### 3.3 AI问答模块

#### 3.3.1 智能问答
- **功能描述**：基于RAG的智能问答，支持上下文记忆
- **输入**：用户问题
- **输出**：AI回答和相关知识来源
- **业务流程**：
  1. 用户提交问题
  2. 系统从知识库检索相关文档
  3. 构建Prompt（包含检索结果和历史对话）
  4. 调用LLM生成回答
  5. 返回回答和来源引用

#### 3.3.2 多轮对话
- **功能描述**：支持上下文记忆的多轮对话
- **输入**：多轮对话内容
- **输出**：基于上下文的连续回答
- **约束条件**：
  - 默认保留最近10轮对话
  - 支持新建会话

#### 3.3.3 图片问答
- **功能描述**：支持图片输入的问答
- **输入**：图片 + 文字问题
- **输出**：基于图片内容的回答
- **技术要求**：
  - 支持Base64编码的图片
  - 调用视觉模型处理

#### 3.3.4 会话管理
- **功能描述**：管理对话历史记录
- **输入**：会话ID
- **输出**：会话详情和消息列表
- **约束条件**：
  - 普通用户最多100条会话记录
  - 会话数据永久保存

### 3.4 作业指引模块

#### 3.4.1 指引生成
- **功能描述**：根据设备型号和故障类型生成标准化作业指导书
- **输入**：
  - 设备型号
  - 故障类型
  - 安全等级
  - 详细程度
- **输出**：结构化的作业指导书文档
- **业务流程**：
  1. 用户选择设备型号和输入故障描述
  2. 系统检索相关作业规范
  3. 调用LLM生成作业指引
  4. 流式返回生成内容
  5. 支持导出为Word文档

#### 3.4.2 指引管理
- **功能描述**：查看和管理历史生成的作业指引
- **输入**：筛选条件（设备类型、时间等）
- **输出**：指引列表
- **约束条件**：
  - 支持查看、删除操作
  - 保留最近100条记录

#### 3.4.3 规程库管理
- **功能描述**：维护作业规程数据库
- **输入**：规程文档
- **输出**：规程列表
- **业务流程**：
  1. 管理员上传作业规程文档
  2. 系统解析并存储
  3. 可用于指引生成参考

### 3.5 案例管理模块

#### 3.5.1 案例创建
- **功能描述**：创建检修案例记录
- **输入**：
  - 案例标题
  - 设备型号
  - 故障类型
  - 故障描述
  - 解决方案
  - 故障分析
  - 维修过程
  - 经验教训
- **输出**：创建成功提示
- **约束条件**：
  - 所有字段必填
  - 附件不超过50MB

#### 3.5.2 案例审核
- **功能描述**：管理员审核用户提交的案例
- **输入**：审核操作（通过/拒绝）+ 审核意见
- **输出**：审核结果
- **业务流程**：
  1. 用户提交案例（状态：待审核）
  2. 管理员查看案例详情
  3. 审核通过（状态：已通过）或拒绝（状态：已拒绝）
  4. 审核通过的案例可参与知识图谱抽取

#### 3.5.3 案例检索
- **功能描述**：检索历史检修案例
- **输入**：关键词、设备类型、时间范围
- **输出**：符合条件的案例列表
- **技术要求**：
  - 支持全文检索
  - 支持分页（默认20条/页）

#### 3.5.4 案例统计
- **功能描述**：统计案例数据
- **输入**：时间范围
- **输出**：统计数据（总数、待审核数、已通过数、已拒绝数）

### 3.6 文档管理模块

#### 3.6.1 文档上传
- **功能描述**：上传检修相关文档
- **输入**：文件（PDF/Word/Excel/PPT/图片等）
- **输出**：上传结果
- **业务流程**：
  1. 用户选择文件
  2. 系统校验文件类型和大小
  3. 解析文档内容（OCR识别、视觉模型描述）
  4. 向量化存储
  5. 提交审核

#### 3.6.2 文档解析
- **功能描述**：智能解析上传的文档
- **技术要求**：
  - PDF：PyMuPDF提取文本和图片
  - Word：python-docx解析
  - 图片：PaddleOCR文字识别
  - 视觉描述：Qwen2-VL图片理解

#### 3.6.3 文档审核
- **功能描述**：管理员审核上传的文档
- **输入**：审核操作（通过/拒绝）+ 审核意见
- **输出**：审核结果

#### 3.6.4 文档预览
- **功能描述**：在线预览文档内容
- **输入**：文档ID
- **输出**：文档内容或预览图

#### 3.6.5 文档下载
- **功能描述**：下载原始文档文件
- **输入**：文档ID
- **输出**：文件下载

### 3.7 知识图谱模块

#### 3.7.1 图谱可视化
- **功能描述**：交互式知识图谱展示
- **输入**：无
- **输出**：图谱可视化界面
- **技术要求**：
  - 力导向布局算法
  - 支持缩放、拖拽、节点点击
  - 节点类型区分（设备、故障、解决方案等）

#### 3.7.2 实体抽取
- **功能描述**：从案例或文档中自动抽取实体和关系
- **输入**：案例ID或文档ID
- **输出**：抽取的实体和关系
- **技术要求**：
  - 调用LLM进行实体识别
  - 支持设备、故障、解决方案、操作流程、标准规范等实体类型

#### 3.7.3 图谱搜索
- **功能描述**：在知识图谱中搜索节点
- **输入**：搜索关键词
- **输出**：匹配的图谱节点
- **约束条件**：
  - 支持按节点类型筛选
  - 支持分页

#### 3.7.4 节点详情
- **功能描述**：查看图谱节点的详细信息
- **输入**：节点ID
- **输出**：节点属性和关联关系

### 3.8 系统管理模块

#### 3.8.1 用户管理
- **功能描述**：管理员管理用户账号
- **输入**：用户操作（创建、修改、删除、审核）
- **输出**：操作结果
- **约束条件**：
  - 只有管理员可执行
  - 系统内置管理员账户

#### 3.8.2 API配置
- **功能描述**：配置LLM和Embedding API参数
- **输入**：
  - API提供商（通义千问/MiniMax/DeepSeek等）
  - API密钥
  - 模型选择
  - 温度参数
  - 最大Token数
- **输出**：配置保存成功提示

#### 3.8.3 检索参数配置
- **功能描述**：配置检索相关参数
- **输入**：
  - TopK结果数
  - 相似度阈值
  - 语义/关键词权重
- **输出**：配置保存成功提示

#### 3.8.4 GPU状态监控
- **功能描述**：实时监控GPU使用状态
- **输入**：无
- **输出**：GPU型号、显存使用、温度等

#### 3.8.5 操作日志
- **功能描述**：记录用户操作日志
- **输入**：无
- **输出**：日志列表
- **约束条件**：
  - 只读权限
  - 保留最近1000条

## 4. 性能需求

### 4.1 响应时间
| 功能模块 | 目标响应时间 | 最大响应时间 |
|---------|-------------|-------------|
| 登录 | < 1s | 3s |
| 知识检索 | < 2s | 5s |
| AI问答 | < 3s | 10s |
| 文档上传 | < 5s | 30s |
| 图谱加载 | < 2s | 5s |

### 4.2 并发能力
- 系统支持至少50个并发用户
- API接口支持60次/分钟的请求频率

### 4.3 可用性
- 系统可用性达到99.5%
- 支持7×24小时连续运行
- 单次故障恢复时间 < 30分钟

### 4.4 存储容量
- 支持管理至少10000条知识文档
- 支持存储至少1000张故障图片
- 单个文件大小支持最大50MB

## 5. 安全需求

### 5.1 认证授权
- 所有API接口需Bearer Token认证
- Token有效期24小时
- 支持权限分级控制

### 5.2 数据安全
- 密码使用bcrypt加密存储
- 敏感配置支持加密存储
- 支持数据备份

### 5.3 接口安全
- 登录接口支持图形验证码
- 支持登录速率限制（防暴力破解）
- XSS、SQL注入防护
- 文件上传类型和大小校验

### 5.4 传输安全
- 支持HTTPS传输
- CORS跨域策略配置
- 安全响应头配置
